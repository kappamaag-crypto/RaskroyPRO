# Проверки Раскрой PRO 5.3.0

## Автоматические тесты

- 10/10 тестов Node.js проходят: регрессия алгоритмов и валидации сохранений.
- 100 детерминированных наборов в проверке алгоритмов.
- Chromium с *моделью* browser storage (заглушки IndexedDB и localStorage): создание ручного снимка, предоперационная и последующая копии, восстановление журнала и склада, автоснимок по таймеру, проверка контрольной суммы, миграция формата 6 → 7, запрет перезаписи версии 100, сохранение данных после проведения склада.
- При отсутствии IndexedDB критическая операция отменяется и появляется предупреждение.
- Отдельная проверка в Chromium: экраны шириной 1440 и 390 пикселей, вкладка восстановления доступна без горизонтального переполнения.

## Ограничение среды тестирования

Полноценный тест на настоящем IndexedDB опубликованного HTTPS-адреса **не выполнен**: автоматизированный браузер в среде сборки блокирует навигацию к локальным и публичным URL. Полнота тестирования IndexedDB проверена только на браузерной модели асинхронных транзакций. Перед производственным использованием рекомендуется проверить создание копии, перезагрузку страницы, восстановление из неё и экспорт JSON уже на GitHub Pages.
