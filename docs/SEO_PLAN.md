# SEO-план «Раскрой PRO»

**Базовая версия:** 5.3.2. **Дата:** 14 ноября 2026.  
**Сайт:** https://raskroy.spk-effa.ru/  
**Цель:** повысить полезный органический трафик Google/Яндекса, не меняя расчётный движок, склад, JSON и локальные резервные копии. Проект остаётся полностью статическим на GitHub Pages.

## Исходное состояние

- В индексе запрашивается один URL `/`: `robots.txt`, `sitemap.xml`, canonical, title, description, Open Graph, favicon и WebApplication JSON-LD уже имеются. Sitemap отправлен пользователем в Google Search Console и Яндекс Вебмастер; запрос переобхода выполнен.
- H1 содержит номер версии. Инструкция и алгоритмы доступны во вкладках, но не имеют самостоятельных адресов.
- Калькулятор работает в браузере; локальные данные заказа и склада нельзя передавать в аналитику.
- Реальные показы/клики/позиции пока не получены. Не подменять их оценками.

## Последовательность реализации

**A. База и защита.** Прочитать `index.html`, текущие тесты, `docs/ALGORITHMS.md`; записать базовую статистику; проверить публикацию.  
**B. Быстрые исправления.** SEO-02/03; видимость текста без JS и мобильная адаптация.  
**C. Полезные страницы.** SEO-04/05, затем SEO-06/07; числовые примеры перепроверить в расчётном движке.  
**D. Технический выпуск.** SEO-08/09, проверка внутренних ссылок, канонических адресов, заголовков, sitemap.  
**E. Исследование спроса.** SEO-10/11/12/13 по действительным данным, а не по догадкам.

## Регрессионные критерии

1. `node --test tests/*.test.cjs` проходит; проверяются расчёт, переносы, склад, JSON, IndexedDB и SEO.
2. На каждой новой индексируемой странице один H1, корректный canonical/title/description, ссылки доступны без JS, нет случайного noindex.
3. Протестированы экраны 320 / 375 / 768 / 1440 px и работа с клавиатуры.
4. Не нарушены расчёт, импорт/экспорт Excel и CSV, печать, журнал, резервные копии.
5. Все изменения фиксируются в README и Git; публикация только после успешного CI.
6. Не обещать гарантированную экономию, точность, рост позиций или сертификацию расчёта.

## Подключённые инструменты и роли

- **GitHub:** код, история, тесты, документация, CI и Pages.
- **OpenSEO:** создан проект «Раскрой PRO — SEO» (ID `fb47ea0e-2b7a-4d45-bfd5-7a8694a225fd`). Контекст продукта сохранён; доступны навыки `seo-project-setup`, `seo-audit`, `keyword-research`, `keyword-clustering`. Начальный баланс — 500 кредитов, исследования не запускались. При создании проекта рынок по умолчанию выставлен US/en: **в будущих запросах обязательно задавать Россию и русский язык**, иначе данные нерелевантны.
- **Агентные роли для работы:** SEO-исследователь, технический разработчик, редактор инженерной документации, QA-проверяющий. Это процессные роли; отдельные автономные агенты сейчас не запущены.
- **Search Console / Яндекс Вебмастер:** пользователь уже подтвердил сайт и отправил Sitemap; для чтения статистики требуется доступ или выгрузка.
- **Context7:** при необходимости проверить актуальные API используемых библиотек.
- **Ahrefs:** доступен, но SEO-данные ограничены тарифом; не делать платных вызовов без необходимости.
