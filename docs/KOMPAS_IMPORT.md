# Импорт ведомостей КОМПАС-3D (.xls / .xlsx)

Начиная с версии 5.4.0, в «Раскрой PRO» есть **отдельная кнопка «Импорт ведомости КОМПАС-3D»**. Ранее существующие режимы **«Импорт деталей CSV»** и **«Вставить из Excel»** сохранены. «Вставить из Excel» означает вставку скопированных ячеек через буфер обмена, а не выбор файла.

## Как пользоваться

1. Экспортируйте спецификацию КОМПАС-3D в Excel 97–2003 (`.xls`) или Excel 2007+ (`.xlsx`).
2. В калькуляторе нажмите «Импорт ведомости КОМПАС-3D» и выберите файл.
3. Откроется окно предварительной проверки; при необходимости выберите лист книги.
4. Проверьте распознанные названия профилей, марки стали, длины в мм и количество. Нераспознанные строки по умолчанию не выбраны для переноса, но их можно исправить и выбрать; детали без линейного профиля исключены.
5. Выберите «Заменить» или «Добавить» и нажмите «Перенести выбранные детали». При замене программа запросит подтверждение. До изменения существующих деталей создаётся резервная копия проекта.
6. **Обязательно проверьте** совпадение профиля и марки стали в разделе «Доступные хлысты и складские остатки». Импорт ведомости не создаёт складские позиции сам.
7. Выполните расчёт раскроя и сверьте результаты с производственной ведомостью.

## Что умеет распознавать

- Столбцы `Наименование`, `Позиция`, `Профиль/Сечение`, `Сталь`, `Длина профиля`, `Количество`, а также таблицы с `column1/column2/...`.
- Наименование вида `Профиль@/Труба 40х40х2,5 ГОСТ 8639-82 / Ст3пс ГОСТ 13663-86 @/L = 285 мм`: распознаётся труба, ГОСТ, марка стали, длина 285 мм.
- Разные длины одного профиля, количество для каждой позиции, несколько листов.
- Значения длины `L=85`, `L = 285 мм` и обычную колонку `Длина профиля`; размер сечения не принимается за длину детали.
- Служебный префикс `Профиль@/` удаляется из названия профиля.

## Проверено на предоставленном отчёте

В исходном файле `пупупу.xls` (книга Excel 97–2003, лист `Report`) присутствуют столбцы `Наименование`, `Количество`, `Масса`, `Длина профиля`.

Обнаружены четыре позиции трубы 40х40х2,5 мм: длина 85 мм × 4 шт., 285 мм × 4 шт., 470 мм × 2 шт., 500 мм × 2 шт. Итого **12 деталей, 3420 мм** чистой длины. «Основание» и «Пластина для колес» исключаются, поскольку не относятся к линейному прокату. Масса не служит источником длины. Автоматические тесты покрывают именно эти табличные значения.

## Ограничения и безопасность

- Чтение `.xls/.xlsx` выполняет клиентская библиотека **SheetJS Community Edition 0.20.3**: она загружается с официального `cdn.sheetjs.com` при первом использовании импорта; необходим доступ к интернету. После загрузки файл разбирается локально в браузере. При недоступности CDN сохраняется возможность импорта через CSV.
- Файл ведомости не отправляется на сервер калькулятора. При подключении сторонней библиотеки присутствует обычный риск выполнения стороннего кода: для полностью автономного/контролируемого окружения в будущем рекомендуется локально включить проверенную версию библиотеки в статические файлы.
- Ограничения: размер до **25 МБ**, не более **30 листов** и **1500 распознаваемых позиций на лист**; при превышении показывается явная ошибка, строки не обрезаются молча.
- Импорт предназначен для линейного проката, а не для листового раскроя, сборок, пластин и крепежа.
- При спорных данных нужно исправить позицию в предпросмотре. Без выбранных корректных строк данные проекта не изменяются.
- При распознавании не используются внешние нейросети. Достоверность результатов не гарантируется для всех возможных форматов спецификаций КОМПАС.
- В калькулятор импортируются только детали; текущий склад, журнал движений и параметры резки сохраняются. Перед реальной резкой необходимо сверить параметры, пропил и торцовку.

## Разработчику

Парсер: `js/kompas-import.js`; предпросмотр: `js/kompas-ui.js`; оформление: `css/kompas-import.css`. Тесты: `tests/kompas-import.test.cjs` и `tests/kompas-real-export.test.cjs`.

Запустить: `node --test tests/*.test.cjs`. Проверить интеграцию в браузере с настоящим `.xls` (включая первое подключение SheetJS и подтверждение предпросмотра) перед массовым использованием.
