# Раскрой PRO

**Раскрой PRO** — бесплатный калькулятор раскроя профильных труб, уголков, швеллеров, двутавров, арматуры и другого длинномерного металлопроката. Он помогает посчитать потребность в хлыстах, составить карты резки и вести учёт пригодных отрезков, которые можно использовать в следующих заказах.

**Открыть калькулятор:** https://raskroy.spk-effa.ru/

## Как пользоваться

Откройте сайт, укажите заказ и заполните ведомость деталей. Для каждой позиции нужны профиль, марка стали, длина и количество. Затем добавьте доступные исходные хлысты. Можно указать несколько стандартных длин и складские остатки; для складских позиций обязательно задайте фактическое количество.

Перед расчётом проверьте ширину пропила, припуски на торцовку и минимальную длину полезного остатка. После нажатия **«Рассчитать раскрой»** программа покажет количество хлыстов, карты резки, координаты, отходы и возвращаемые на склад отрезки. Отчёт можно сохранить в Excel или CSV, карты — распечатать.

Длины вводятся в миллиметрах, допускаются дробные значения до 0,001 мм. Кнопки **−** и **+** меняют длину на 1 мм. Количество деталей и хлыстов указывается целыми числами.

### Режимы расчёта

- **Быстрый** — несколько простых способов разложить детали по хлыстам.
- **Сбалансированный** — дополнительный подбор сочетаний размеров, переносы деталей и пересборка части плана.
- **Углублённый** — более широкий поиск вариантов. Может работать дольше.
- **Точный** — для небольших заказов старается проверить все допустимые схемы. Если полный поиск завершился, программа отдельно сообщает о доказанной оптимальности. В остальных случаях результат считается приближённым.

В сбалансированном и более глубоких режимах программа может **перемещать деталь из одного хлыста в другой** или **менять две детали местами**. Эти операции происходят автоматически. Для такого локального улучшения предусмотрено ограничение до 36 хлыстов; операция применяется только тогда, когда улучшает выбранный показатель. Ручного перетаскивания деталей мышью пока нет.

**Приоритет склада** можно выбрать отдельно: экономический — минимизировать выбранные расходы или отходы; строгий — по возможности сначала расходовать складские отрезки. Строгий режим не обязательно даст самую дешёвую закупку.

## Склад, заказы и сохранение данных

Расчёт не меняет склад. После фактической резки и проверки результатов используется кнопка **«Провести склад»**: использованные складские отрезки списываются, подходящие хвосты добавляются на склад, а операция записывается в журнал. Прежде чем проводить заказ, проверьте реальные длины и номера позиций.

Рабочий проект сохраняется **в браузере на этом устройстве**. Дополнительные резервные копии создаются локально и доступны через кнопку **«Резервные копии»**. Для переноса между компьютерами или долгосрочного хранения обязательно выгружайте проект в JSON — например, в папку на SSD. Очистка данных сайта может удалить и рабочий проект, и встроенные резервные копии.

Приложение работает по адресу сайта, но **сервер не получает ваши ведомости или складские данные**: вычисления выполняются в браузере. Общего склада между разными компьютерами без обмена JSON нет.

## Для разработчиков и тех, кто развёртывает сайт

Проект состоит из статического `index.html`. Для размещения без серверной части используется GitHub Pages; публикуется ветка `main`, папка `/(root)`. Адрес сайта задаётся файлом `CNAME`. Сохранённые данные привязаны к адресу сайта и профилю браузера.

Проверка расчётного ядра и резервных копий (нужен Node.js 22 или новее):

```bash
node --test tests/*.test.cjs
```

Технические сведения приведены в `docs/ALGORITHMS.md` и `docs/BACKUPS.md`.

## Важное ограничение

Калькулятор предоставляется на условиях «как есть» без каких-либо гарантий точности и бесперебойной работы. Полученные данные являются справочными. Пользователь самостоятельно проверяет результаты и несет полную ответственность за решения, принятые на их основе.

Перед производственной резкой обязательно проверьте исходные размеры, точность оборудования, пропил, торцевые припуски, возможность зажима детали и соответствие карт требованиям конкретного заказа.
